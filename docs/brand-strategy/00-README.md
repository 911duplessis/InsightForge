## One-paragraph summary

InsightForge is a strategic intelligence and execution ecosystem, not an IT vendor. It sells
clarity first (Discovery, via the FORGE Framework and the VDOS engine already implemented in
this repo) and builds second — websites, apps, AI systems, and automation only after a client's
market, risks, and roadmap have been made explicit and evidence-backed. The commercial engine
is the same three-tier structure PrimeTurf and Ready & Rooted are already running through this
platform: **Master Blueprint (Discovery) → Build → Scale (retained optimisation)**, sold either
as a full VDOS engagement (11-stage, ASQ-validated, resumable/auditable) or FORGE Lite (single-
shot intake → report) depending on the client's size and urgency.
