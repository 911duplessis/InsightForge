# 13. Service Catalogue

## Tier 1 — Discovery (Forge Framework applied once or eleven times)

| Service | What it is | Depth | Typical output |
|---|---|---|---|
| **FORGE Lite** | Single-shot 10-step intake → one Claude analysis pass | Fast, fixed-fee, no human review gate between stages | One report: executive summary, current-reality analysis, business-model analysis, customer analysis, market-gap analysis, revenue leaks, opportunity matrix |
| **VDOS (Venture Discovery Operating System)** | 11-stage gated methodology, Stage 0 Assumption Destruction + Stages 1–11 | Deep, resumable, human-reviewed at gates, validated by 6 ASQ evidentiary instruments | A full Master Blueprint: venture thesis, MVP scope, category-creation opportunity, brand discovery, and VOS (venture operating system) design — persisted and auditable stage by stage |

## Tier 2 — Master Blueprint (the Forge-phase deliverable, sellable standalone)

- Strategic positioning and brand identity direction
- Technology roadmap
- Growth strategy
- Competitive-advantage summary
- Implementation plan with investment/timeline attached

Sold as its own line item — a client can buy only this and implement it elsewhere. This is
deliberate (see `01-brand-identity.md`'s "build only after clarity" value).

## Tier 3 — Build (Development)

| Service | Scope |
|---|---|
| Websites | Marketing sites, e-commerce, content platforms — scoped from the Blueprint's roadmap |
| Applications | Web and mobile apps, scoped the same way |
| AI systems | Custom AI-driven automation, chat/agent products, internal tools |
| Automation | Workflow automation connecting existing client systems |
| Digital infrastructure | Cloud architecture, multi-tenant systems, hosting setup |

All Build-phase work is milestone-priced against the Blueprint's own roadmap
(`08-business-model-revenue.md`) — InsightForge does not quote Build work without a preceding
Blueprint, whether that Blueprint came from InsightForge or (rarely) elsewhere.

## Tier 4 — Scale (retained)

| Service | Cadence |
|---|---|
| SEO | Ongoing, reported monthly against Blueprint KPIs |
| Analytics | Continuous, surfaced in the client portal |
| Optimisation | Iterative, tied to the Growth phase of the FORGE Framework |
| Market expansion | Periodic, triggered by Phase 7 (Continuous Evolution) re-Discovery |

Priced as renewable monthly retainers, cancellable with notice — never a locked annual
contract (see `08-business-model-revenue.md`).

## Add-on / ecosystem services

- **Partner-sourced services** (hosting, cloud, cybersecurity, hardware, AI tools, marketing
  platforms, payment solutions) — recommended, not resold, per
  `07-partner-ecosystem-strategy.md`'s transparency rules.
- **Corporate identity package** — logo, colour system, typography, presentation/report
  templates, dashboard design — per `02-corporate-identity-guide.md`, sold as part of a
  Blueprint or standalone for a rebrand-only engagement.

## How to quote a new prospect (decision rule for sales)

1. Unknown/early-stage, budget-constrained, wants a fast read → **FORGE Lite**.
2. Established business, high-stakes decision, wants an auditable process → **VDOS**.
3. Already has a strategy document from elsewhere and just wants execution → **Build only**,
   but only after InsightForge reviews the existing strategy against the FORGE lens first (a
   short, cheap "Blueprint validation" pass) — never accept an unvalidated third-party
   strategy as a Build brief without this check, since a bad Build built on bad Discovery is
   the exact failure mode InsightForge exists to prevent.
